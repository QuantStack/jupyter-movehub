# ipymovehub

[![ipymovehub](https://img.shields.io/badge/notebook-link-e2d610?logo=jupyter&logoColor=white)](https://notebook.link/@quantstack/movehub)

A JupyterLab extension to connect to a Move Hub and drive robots.

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install ipymovehub
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall ipymovehub
```
