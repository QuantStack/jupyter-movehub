# jupyter_movehub

A JupyterLab extension to connect to a Lego Move Hub and drive Legoboost robots.

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install jupyter_movehub
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall jupyter_movehub
```
